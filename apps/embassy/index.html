🎯 NIP-57 Zap Flow Reference
  1. Fetch recipient's Lightning Address from their profile (kind 0) metadata
  2. Query LNURL endpoint to get callback URL and verify zaps are supported
  3. Create a zap request (kind 9734 event) with amount and optional comment
  4. Sign the zap request with your private key (via NostrPass)
  5. Send to Lightning Service Provider who generates invoice
  6. Pay the Lightning invoice using your Lightning wallet
  7. LSP publishes zap receipt (kind 9735) to relays as proof of payment

💡 Tip: This console helps you create and sign the zap request (step 3-4). You'll need a Lightning wallet to complete the payment flow and a Lightning Service Provider (LSP) to handle the invoice generation.
